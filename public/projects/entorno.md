## Objetivo

Desarrollar una herramienta que permita preparar un entorno de trabajo Linux personalizado mediante la instalación y configuración automatizada de sus principales componentes, aplicaciones y preferencias visuales.

## Problema

Configurar un escritorio Linux desde cero requiere instalar múltiples herramientas, organizar sus archivos de configuración y ajustar individualmente las aplicaciones para conseguir un entorno de trabajo coherente. Repetir este proceso manualmente puede consumir tiempo y producir diferencias entre instalaciones.

## Resolución

Desarrollé un script en Bash que reúne la instalación de dependencias y la aplicación de configuraciones en un único procedimiento. La herramienta integra componentes para la gestión de ventanas, terminal, edición de texto, personalización visual y administración de herramientas de desarrollo.

Además, contempla la configuración de distintos elementos del entorno de usuario y del administrador, permitiendo centralizar gran parte de los ajustes necesarios para preparar el escritorio.

## Conocimientos aplicados

- Automatización de tareas mediante Bash.
- Administración de paquetes y servicios en Linux.
- Configuración de shells y aplicaciones de terminal.
- Personalización de entornos de escritorio.
- Integración de herramientas y archivos de configuración.

## Resultado

Una herramienta orientada a reducir el trabajo manual de configuración y facilitar la preparación de un entorno Linux personalizado, reuniendo en un mismo proceso las principales tareas necesarias para establecer un escritorio de trabajo consistente.
